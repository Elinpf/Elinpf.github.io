## 需求

1. 一台8卡H200算力服务器
2. vllm需要 0.10.12+

vllm官方给的启动参数方案

[https://docs.vllm.ai/projects/recipes/en/latest/Qwen/Qwen3.5.html](https://docs.vllm.ai/projects/recipes/en/latest/Qwen/Qwen3.5.html)

h200可以下载`vllm/vllm-openai:nightly`

如果是B200这种Blackwall架构，需要使用`vllm/vllm-openai:cu130-nightly`

## 启动参数

```Markdown
vllm serve Qwen/Qwen3.5-397B-A17B-FP8 \
  --tensor-parallel-size 8 \
  --pipeline-parallel-size 1 \  # 单节点无需PP
  --max-model-len 262144 \
  --gpu-memory-utilization 0.90 \
  --reasoning-parser qwen3 \
  --enable-auto-tool-choice \
  --tool-call-parser qwen3_coder \
  --enable-prefix-caching \  # 加速长上下文
  --enforce-eager \  # 如遇CUDA graph问题可添加
  --mm-encoder-tp-mode data \ # 多模态支持
  --mm-processor-cache-type shm \ # 共享内存
  --dtype bfloat16  # H200支持BF16原生加速
```
