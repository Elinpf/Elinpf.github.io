Prefix命令是: `Ctrl + B`

### 一、核心概念（先理解，再用命令）

tmux 的层级关系：`会话(Session)` → `窗口(Window)` → `面板(Pane)`

- **会话**：独立的运行环境，可后台挂起（核心优势）；
- **窗口**：会话内的标签页，类似浏览器标签；
- **面板**：窗口内的分屏（横向 / 纵向），可同时显示多个终端。
### 二、基础操作（会话管理）

tmux 所有命令的**前缀键**默认是 `Ctrl + b`（先按 `Ctrl+b` 松手，再按后续键），下文简写为 `Prefix`。

| 操作场景 | 命令 / 快捷键 | 说明 |
| --- | --- | --- |
| 创建新会话 | `tmux` / `tmux new -s 会话名` | 后者指定会话名（推荐，便于管理），例如 `tmux new -s dev` |
| 列出所有会话 | `tmux ls` | 查看当前后台的 tmux 会话（ID + 名称 + 状态） |
| 进入已有会话 | `tmux attach -t 会话名/ID` | 例如 `tmux attach -t dev` 或 `tmux a -t 0`（ID 为 0 的会话） |
| 重命名会话 | `tmux rename-session -t 旧名 新名` | 例如 `tmux rename-session -t dev web-dev` |
| 重命名窗口 | `tmux rename-window <new>` |  |
| 临时脱离会话（后台运行） | `Prefix + d` 或 `tmux detach` | 断网 / 登出后，会话内程序仍运行，重新登录后用 `tmux a` 恢复 |
| 强制关闭会话 | `tmux kill-session -t 会话名/ID` | 例如 `tmux kill-session -t dev` |
| 关闭所有会话 | `tmux kill-server` | 慎用！会终止所有 tmux 会话 |
| 切换会话 | `Prefix + s` | 弹出会话列表，用方向键选择，回车进入（可视化切换） |

### 三、窗口管理（会话内多标签）

| 操作场景 | 快捷键 / 命令 | 说明 |
| --- | --- | --- |
| 新建窗口 | `Prefix + c` | 会话内创建新窗口，默认命名为数字（0、1、2...） |
| 切换窗口 | `Prefix + 数字`（0/1/2...） | 直接切换到对应数字的窗口 |
| 切换上 / 下一个窗口 | `Prefix + p` / `Prefix + n` | p=previous，n=next |
| 重命名窗口 | `Prefix + ,`（逗号） | 输入新名称后回车（便于识别窗口用途，如 `logs`/`code`） |
| 关闭当前窗口 | `Prefix + &`（按 & 后需确认 y/n） | 关闭窗口，若窗口是会话最后一个，会话也会关闭 |
| 列出所有窗口 | `Prefix + w` | 弹出窗口列表，方向键选择切换 |

### 四、面板管理（窗口内分屏，高频！）

| 操作场景 | 快捷键 | 说明 |
| --- | --- | --- |
| 纵向分屏（左右） | `Prefix + %` | 将当前面板拆分为左右两个 |
| 横向分屏（上下） | `Prefix + "`（双引号） | 将当前面板拆分为上下两个 |
| 切换面板 | `Prefix + 方向键`（↑↓←→） | 切换到相邻面板 |
| 快速切换面板 | `Prefix + o`（字母 o） | 按顺序切换所有面板 |
| 调整面板大小 | `Prefix + 按住方向键` | 长按方向键可逐步调整面板大小（例如 `Prefix + 按住→` 扩大当前面板宽度） |
| 关闭当前面板 | `Prefix + x`（按 x 后需确认 y/n） | 关闭面板，若窗口是最后一个面板，窗口也会关闭 |
| 面板全屏 / 还原 | `Prefix + z` | 当前面板全屏显示，再按一次还原 |
| 面板布局重置 | `Prefix + 空格键` | 循环切换预设布局（均分、主副面板等） |

## 常用组合

```Bash
apt install -y tmux
echo "alias tmuxr='tmux new -A -s'" >> ~/.bashrc
```

```Bash
tmux new -s pf
tmux new -A -s pf # 没有就创建,有就进入

tmux a -t pf

tmux ls

alias tmuxr='tmux new -A -s'

prefix + d # 脱离
prefix + s # 切换绘画
prefix + % # 左右分屏
prefix + w # 列出所有窗口
prefix + c # 创建新窗口
prefix + 数字 # 切换窗口

# 跳转
prefix + l # 上一次活动会话（只在本windows内）
prefix + b # 下一个会话
prefix + p # 上一个会话

# 如果是vim里面会抓取鼠标事件, 临时先在vim中禁止
:set mouse=

tmux rename-windows
tmux rename-session

# 迁移到其他session
tmux move-window <session>:
```

配置

```Bash
# 彻底禁用 tmux 鼠标
set -g mouse off
```
