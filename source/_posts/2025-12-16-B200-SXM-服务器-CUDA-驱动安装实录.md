**你的系统处于矛盾状态**：安装了`nvidia-driver-open`包（开源驱动元包），但内核模块签名验证失败，且**缺少关键的Fabric Manager服务**。

问题根源

B200 GPU要求：

1. **必须使用开源内核模块**（日志明确提示）
2. **必须安装并启动nvidia-fabricmanager服务**（多GPU通信必需）
3. **模块签名问题**导致驱动无法完全初始化

### 清理脚本

```Bash
#!/bin/bash
set -e

echo "========================================"
echo "  NVIDIA/CUDA 完全通用清理工具"
echo "========================================"
echo "⚠️ 警告：这将自动检测并移除系统上所有 NVIDIA/CUDA 版本"
echo ""

read -p "是否继续? (y/N): " -n 1 -r
echo
if [[ ! $REPLY =~ ^[Yy]$ ]]; then
    echo "操作已取消"
    exit 1
fi

# 1. 停止所有 NVIDIA 相关服务
echo "停止 NVIDIA 服务..."
sudo systemctl stop nvidia-persistenced.service 2>/dev/null || true
sudo systemctl stop nvidia-fabricmanager.service 2>/dev/null || true
sudo systemctl stop nvidia-powerd.service 2>/dev/null || true

# 2. 自动检测所有 CUDA 软件包
echo "检测 CUDA 软件包..."
CUDA_PKGS=$(dpkg -l | grep -E '^ii.*cuda' | awk '{print $2}' | tr '\n' ' ')
if [ ! -z "$CUDA_PKGS" ]; then
    echo "找到以下 CUDA 软件包:"
    echo "$CUDA_PKGS" | tr ' ' '\n' | sed 's/^/- /'
    echo "正在卸载..."
    sudo apt-get --purge remove -y $CUDA_PKGS
else
    echo "未发现 CUDA 软件包"
fi

# 3. 自动检测所有已安装的 NVIDIA 软件包
echo "检测 NVIDIA 软件包..."
NVIDIA_PKGS=$(dpkg -l | grep -E '^ii.*(nvidia-driver|nvidia-kernel|nvidia-fabricmanager|cuda)' | awk '{print $2}' | tr '\n' ' ')
if [ ! -z "$NVIDIA_PKGS" ]; then
    echo "找到以下 NVIDIA 软件包:"
    echo "$NVIDIA_PKGS" | tr ' ' '\n' | sed 's/^/- /'
    echo "正在卸载..."
    sudo apt-get --purge remove -y $NVIDIA_PKGS
else
    echo "未发现 NVIDIA 软件包"
fi

# 4. 清理其他相关包
echo "检测其他相关包..."
OTHER_PKGS=$(dpkg -l | grep -E '^ii.*(libnvidia|libxnvctrl|libcublas|libcufft|libcurand)' | awk '{print $2}' | tr '\n' ' ')
if [ ! -z "$OTHER_PKGS" ]; then
    sudo apt-get --purge remove -y $OTHER_PKGS 2>/dev/null || true
fi

# 5. 清理 DKMS 模块（自动检测所有版本）
echo "清理 DKMS 模块..."
if command -v dkms &> /dev/null; then
    NVIDIA_DKMS=$(dkms status | grep -i nvidia | awk -F: '{print $1}' | tr '\n' ' ')
    if [ ! -z "$NVIDIA_DKMS" ]; then
        for module in $NVIDIA_DKMS; do
            echo "移除 DKMS 模块: $module"
            sudo dkms remove "$module" --all 2>/dev/null || true
        done
    fi
fi

# 6. 删除所有 NVIDIA/CUDA 仓库配置
echo "清理仓库配置..."
sudo rm -f /etc/apt/preferences.d/cuda-repository-pin-600
sudo rm -f /etc/apt/sources.list.d/cuda*
sudo rm -f /etc/apt/sources.list.d/nvidia*
sudo rm -f /usr/share/keyrings/cuda-archive-keyring.gpg
sudo rm -f /usr/share/keyrings/nvidia-container-toolkit-keyring.gpg

# 7. 删除残留文件和目录
echo "清理残留文件..."
sudo rm -rf /usr/local/cuda*
sudo rm -rf /opt/cuda*
sudo rm -rf /usr/lib/cuda*
sudo rm -rf /usr/include/cuda*
sudo rm -rf /usr/share/cuda*
sudo rm -rf /etc/cuda*
sudo rm -rf /var/lib/dkms/nvidia*
sudo rm -rf /usr/src/nvidia-*
sudo rm -rf /usr/lib/nvidia-*

## 清理内核文件
sudo find /lib/modules/ -path "*/updates/dkms/nvidia*" -delete

## stubs 目录
rm -rf /usr/lib/x86_64-linux-gnu/stubs
## 重建 stubs 目录，避免下次安装报错
mkdir -p /usr/lib/x86_64-linux-gnu/stubs

# 8. 清理 modprobe 配置
echo "清理 modprobe 配置..."
sudo rm -f /etc/modprobe.d/nvidia*.conf
sudo rm -f /lib/modprobe.d/nvidia*.conf

# 9. 清理 udev 规则
echo "清理 udev 规则..."
sudo rm -f /etc/udev/rules.d/99-nvidia*.rules

# 10. 清理 X11 配置
echo "清理 X11 配置..."
sudo rm -f /etc/X11/xorg.conf.d/10-nvidia.conf
sudo rm -f /etc/X11/xorg.conf

# 11. 清理环境变量
echo "清理环境变量..."
for rcfile in ~/.bashrc ~/.zshrc ~/.profile; do
    if [ -f "$rcfile" ]; then
        cp "$rcfile" "$rcfile.backup.$(date +%Y%m%d%H%M%S)" 2>/dev/null || true
        sed -i '/CUDA_HOME/d' "$rcfile" 2>/dev/null || true
        sed -i '/export PATH=.*cuda/d' "$rcfile" 2>/dev/null || true
        sed -i '/export LD_LIBRARY_PATH=.*cuda/d' "$rcfile" 2>/dev/null || true
        sed -i '/Nsight/d' "$rcfile" 2>/dev/null || true
    fi
done

# 12. 更新系统
echo "更新系统..."
sudo apt-get autoremove -y
sudo apt-get autoclean -y
# sudo apt-get update
sudo update-initramfs -u

# 13. 最终验证
echo "========================================"
echo "验证清理结果："
echo "--- 剩余 NVIDIA 软件包 ---"
dpkg -l | grep -E '^ii.*nvidia' || echo "✅ 无 NVIDIA 软件包"

echo "--- 剩余 CUDA 软件包 ---"
dpkg -l | grep -E '^ii.*cuda' || echo "✅ 无 CUDA 软件包"

echo "--- 剩余相关库 ---"
dpkg -l | grep -E '^ii.*(libnvidia|libxnvctrl)' || echo "✅ 无相关库"

echo "--- DKMS 模块状态 ---"
dkms status | grep -i nvidia || echo "✅ 无 NVIDIA DKMS 模块"

echo "========================================"
echo "✅ 通用清理完成！"
echo "系统已完全准备好安装任何版本 NVIDIA/CUDA"
echo "建议重启: sudo reboot"
echo "========================================"
```

# 总结

1. 由于这次的B200 是SXM的制式, 采用第四代NVSwitch, 
   1. 加入了NVLSM
   2. 所以需要安装 FabricManager
2. FabricManager 依赖 nvlsm, 所以也需要同步安装
3. 需要保证 nvidia 驱动版本, cuda 版本完全一致才行, 否则直接重装
4. nvidia-smi 是安装cuda驱动才可以使用的
5. 要使用开源的nvidia驱动(nvidia-open), 否则会直接找不到device(在dmesg中会明确写出来)
6. 清理cuda 和nvidia驱动, 使用的是4层清理法
7. 当出现问题, 从nvidia 驱动版本, cuda 驱动版本, nvidia-fabricmanager 运行状态, dmesg 日志等地方来排查
