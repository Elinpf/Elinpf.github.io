## 配置思路

1. 基础网络配置
2. SSH登录配置
3. 将异步串口的工作模式配置为流模式
4. 配置 TTY 用户线

### 基础网络配置

保证路由可达即可

### SSH登录配置

- `public-key local create rsa` 生成RSA密钥对
- 正常配置SSH和用户
### 将异步串口改为流模式

```YAML
[Router] interface async 6/0
[Router-Async6/0] async-mode flow
[Router-Async6/0] quit
```

配置时可以关闭电平检测，这样的话，就不会检测是否有信号，一直处于UP状态。后面关掉即可

```YAML
interface async 6/0
 detect dsr-dtr
```

### 配置TTY 用户线

首先需要知道异步串口和TTY用户线的对应关系

- `display user-interface`
知道对应关系后，根据对应的TTY用户线，配置重定向

重定向分为telnet和ssh，区别就是，使用telnet进行重定向，输入用户明密码就直接是目标机器的，而ssh，则需要先输入本机的用户密码。

对应的监听端口，可以先提前统一，方便记忆

#### Telnet反向登录

```YAML
line tty 97
 
 redirect enable
 redirect listen-port 5097 # 设置 Telnet 重定向的监听端口号为 5097
 redirect timeout 0 # 设置 Telnet 重定向的空闲超时时间为 0，表示永不超时
 flow-control none #设置不进行流量控制
 undo shell #终止终端fu
 quit
```

#### SSH反向登录

```YAML
line tty 81
 redirect enable
 redirect listen-port 30000
 redirect timeout 60  #0表示永不超时
 flow-control none
 undo shell
 user-role network-operator
 ssh redirect enable
 ssh redirect listen-port 40000 # 这个才是对外监听的地址，也是访问的端口
 ssh redirect timeout 60
```

## 线缆

采用的是串口直通线

线序为：

```YAML
sideA: 橙白 橙 绿白 蓝 蓝白 绿 棕白 棕
sideB: 棕 棕白 绿 蓝白 蓝 绿白 橙 橙白  (修改这一边的线序)
```

## 操作

- 使用 telnet或者ssh访问路由器对应端口
- 通过`~.` 快捷键断开链接
