### 安装PostgreSQL

- 安装postgresql，并进行初始化
```Bash
sudo yum install -y postgresql-server
sudo postgresql-setup --initdb
```

- 由于需要使用独立的用户密码登录pg，所以要用MD5验证方式。
```Bash
# /var/lib/pgsql/data/pg_hba.conf

host    all             all             127.0.0.1/32            md5
host    all             all             ::1/128                 md5
```

- 让pg启动，并伴随开机启动
```Bash
sudo systemctl enable --now postgresql
psql -V # 观察是否安装正常，和版本
```

- 使用最高权限登录pg
通过postgres用户执行psql命令，作为最高权限使用PostgreSQL

```Bash
sudo -u postgres psql
```

- 创建数据库
```Bash
CREATE DATABASE netbox;
CREATE USER netbox WITH PASSWORD 'AcwGOa3NdFU2';
ALTER DATABASE netbox OWNER TO netbox;
-- the next two commands are needed on PostgreSQL 15 and later
\connect netbox;
GRANT CREATE ON SCHEMA public TO netbox;                                        
```

- 验证状态
```Bash
[root@netbox-server ~]# psql --username netbox --password --host localhost netbox
Password: 
psql (13.11)
Type "help" for help.

netbox=> \conninfo
You are connected to database "netbox" as user "netbox" on host "localhost" (address "::1") at port "5432".
netbox=> \q
```

#### 下载源码

- netbox是python写的，所以可以直接使用下载源码的方式
- 使用git或者直接下载然后rz传上去都可以
使用rz上传tar文件，然后把文件解压到`/opt`目录下，最后`ln -s`，创建一个软连接，来保证去掉了版本信息

```Bash
sudo wget https://github.com/netbox-community/netbox/archive/refs/tags/vX.Y.Z.tar.gz
sudo tar -xzf vX.Y.Z.tar.gz -C /opt
sudo ln -s /opt/netbox-X.Y.Z/ /opt/netbox
```

#### 创建应用对应的系统用户

因为要在这个用户下面配置WSGI和HTTP服务，并且也有几个目录是netbox专属所需要的

```Bash
sudo groupadd --system netbox
sudo adduser --system -g netbox netbox
sudo chown --recursive netbox /opt/netbox/netbox/media/
sudo chown --recursive netbox /opt/netbox/netbox/reports/
sudo chown --recursive netbox /opt/netbox/netbox/scripts/
```

> 这里和nautobot给的安装方式是不一样的，nautobot使用的是
`sudo useradd --system --shell /bin/bash --create-home --home-dir /opt/nautobot nautobot`
区别在于将/opt/nautobot作为了home目录

#### 配置

复制一份配置文件，主要对allowed_hosts，database，redis，secret_key进行配置

```Bash
cd /opt/netbox/netbox/netbox/
sudo cp configuration_example.py configuration.py
```

其中`secret_key`是用来对多服务之间的一直会话验证的手段，应该就是类似于保证LB下发到不同服务器，会话都能验证一致性的东西

```Bash
python3 ../generate_secret_key.py
```

#### 执行安装脚本

这个安装脚本包含了一下内容：

1. 创建python的venv虚拟环境
2. 安装所有依赖的python包
3. 执行数据库迁移
4. 创建本地doc文档
5. 聚合静态资源
```Bash
sudo /opt/netbox/upgrade.sh
```

#### 创建netbox的超级用户

```Bash
source /opt/netbox/venv/bin/activate

cd /opt/netbox/netbox
python3 manage.py createsuperuser
> admin / <你的密码>
```

#### 周期执行清理操作

```Bash
sudo ln -s /opt/netbox/contrib/netbox-housekeeping.sh /etc/cron.daily/netbox-housekeeping
```

#### 测试netbox服务是否正常

```Bash
python3 manage.py runserver 0.0.0.0:8000 --insecure
```

### 运行Gunicorn

关于Gunicorn，是一个WSGI接口，用于将请求转化为web框架的环境变量，使开发者无需关心HTTP的通讯细节。

- 将配置拷贝出来使用
```Bash
sudo cp /opt/netbox/contrib/gunicorn.py /opt/netbox/gunicorn.py
```

- 管理netobx的服务
```Bash
sudo cp -v /opt/netbox/contrib/*.service /etc/systemd/system/
sudo systemctl daemon-reload

sudo systemctl enable --now netbox netbox-rq
systemctl status netbox.service # 检查服务
```

#### 获取SSL证书

要使用HTTPS，要么得从提供商购买并在CA认证，要么就自己生成一个。自己生成的话，浏览器就会提示不信任，但是可以用作测试

```Bash
sudo openssl req -x509 -nodes -days 365 -newkey rsa:2048 \
-keyout /etc/ssl/private/netbox.key \
-out /etc/ssl/certs/netbox.crt
```

> 这里展示了放置ssl key 的常用目录 `/etc/ssl/certs`(.crt的公钥) 和` /etc/ssl/private`（.key的私钥）

#### 安装Nginx

- 安装
```Bash
sudo apt install -y nginx
```

- 复制Nginx配置文件
```Bash
sudo cp /opt/netbox/contrib/nginx.conf /etc/nginx/conf.d/netbox.conf
```

主要是修改`server_name`

- 注释掉nginx.conf里面的80端口服务，防止冲突
- 启动nginx
```Bash
sudo systemctl restart nginx
```

## 版本升级

netbox的版本升级本质上是一个手动覆盖的过程，并且在升级前阅读[发行说明](https://docs.netbox.dev/en/stable/release-notes/)

### 手动下载release

下载更新的版本，并替换`/opt/netbox`

```Bash
# Set $NEWVER to the NetBox version being installed
NEWVER=3.5.0
wget https://github.com/netbox-community/netbox/archive/v$NEWVER.tar.gz
sudo tar -xzf v$NEWVER.tar.gz -C /opt
sudo ln -sfn /opt/netbox-$NEWVER/ /opt/netbox
```

### 复制必要的配置文件

```Bash
# Set $OLDVER to the NetBox version currently installed
OLDVER=3.4.9
sudo cp /opt/netbox-$OLDVER/local_requirements.txt /opt/netbox/
sudo cp /opt/netbox-$OLDVER/netbox/netbox/configuration.py /opt/netbox/netbox/netbox/
sudo cp /opt/netbox-$OLDVER/netbox/netbox/ldap_config.py /opt/netbox/netbox/netbox/
sudo cp -pr /opt/netbox-$OLDVER/netbox/media/ /opt/netbox/netbox/
sudo cp -r /opt/netbox-$OLDVER/netbox/scripts /opt/netbox/netbox/
sudo cp -r /opt/netbox-$OLDVER/netbox/reports /opt/netbox/netbox/
sudo cp /opt/netbox-$OLDVER/gunicorn.py /opt/netbox/
```

### 执行更新脚本

```Bash
sudo ./upgrade.sh
```

脚本会做的事情：

1. 摧毁重建python虚拟环境（因为虚拟环境是放在版本目录下的，所以互不影响）
2. 安装所需python包
3. 安装额外的插件包
4. 数据库迁移
5. 生成离线文档
6. 聚合静态资源
7. 从数据库中删除过时的内容类型
8. 从数据库中删除所有过期的用户会话
### 重启服务

```Bash
sudo systemctl restart netbox netbox-rq
```
