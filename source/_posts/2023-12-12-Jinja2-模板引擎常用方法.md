### include引入

通过`<% include 'file' %>`将其他模板直接引入进来

### 控制空白

在开始或结束放置一个减号（ `-` ），可以移除块前或块后的空白。

### env中未找到文件

jinja2有个很让人头疼的问题，就是所有的路径连接符都是`/`，这就导致windows使用 `os.path.join`的时候，会变成`\\`，而导致失败

所以解决办法只能是进行替换

### 严格匹配

默认情况下，访问未定义的变量的时候，返回一个空字符串，所以这时候需要修改`undefined`，让他抛出异常

```Python
from jinja2 import StrictUndefined

env.undefined = StrictUndefined
```

## 添加过滤器

由于有时候jinji2无法处理很复杂的操作，所以可以将函数写到python中，然后注册为过滤器的方式，进行调用

```Python
{%- set ifaces = port|add_interfaces(port_25g) %}
```

```Python
def add_interfaces(ports: Union[List[str], str], port_type: str) -> List[str]:
    """
    根据端口类型和端口编号生成接口字符串列表。
    """
    ifaces = []
    if isinstance(ports, list):
        for p in ports:
            ifaces.append("{} 1/0/{}".format(port_type, p))
            ifaces.append("{} 2/0/{}".format(port_type, p))
    else:
        ifaces.append("{} 1/0/{}".format(port_type, ports))
        ifaces.append("{} 2/0/{}".format(port_type, ports))
    return ifaces   
```
