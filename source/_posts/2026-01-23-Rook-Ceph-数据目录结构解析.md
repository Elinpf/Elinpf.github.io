### **核心架构理解**

```Markdown
/var/lib/rook/                          # Rook管理根目录
├── <mon-X>/                           # MON节点专属数据
│   └── data/                          # MON数据库和密钥
├── rook-ceph/                         # 集群全局配置
│   └── <cluster_fsid>_<osd_fsid>/     # OSD实例身份目录
└── exporter/                          # 监控指标收集
```

### mon结构

```Markdown
mon-e/data/
├── keyring              # MON认证密钥（谁可以访问我）
├── kv_backend           # 存储后端类型（rocksdb）
├── store.db/            # MON元数据库（PG分布、OSD拓扑）
│   ├── 000042.sst       # 有序的键值存储文件
│   ├── CURRENT          # 当前活跃的数据库版本
│   ├── MANIFEST-000010  # 数据库元数据索引
│   └── OPTIONS-000012   # RocksDB配置参数
└── external_log_to      # 外部日志配置
```

### osd身份目录

```Markdown
rook-ceph/
├── client.admin.keyring   # 万能admin密钥（恢复关键）
├── rook-ceph.config       # 集群连接配置
└── 5bbcee9d..._026b2c41.../  # OSD唯一身份目录
    ├── block -> /dev/sdc    # 指向实际数据设备
    ├── ceph_fsid            # 所属集群ID（5bbcee9d...）
    ├── fsid                 # OSD自身ID（026b2c41...）
    ├── keyring              # OSD认证密钥
    ├── ready                # 启动标记（存在=可启动）
    ├── require_osd_release  # 最小Ceph版本要求
    ├── type                 # 存储类型（bluestore）
    └── whoami               # OSD数字ID（如"0"）
```

### Exporter套接字

```Markdown
exporter/
├── ceph-mon.e.asok        # MON套接字（进程间通信）
└── ceph-osd.0.asok        # OSD套接字
```
