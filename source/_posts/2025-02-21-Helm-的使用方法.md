## 什么是helm

**Helm** 是 Kubernetes 的包管理工具，用于简化在 Kubernetes 集群中部署、管理和升级应用程序的过程。类似于 Linux 系统中的 `apt` 或 `yum`，Helm 通过预定义的**软件包（称为 Chart）**，帮助用户快速安装和管理复杂的 Kubernetes 应用。

---

### **核心概念**

1. **Chart**  
   - Helm 的软件包格式，包含一组 Kubernetes 资源定义文件（如 Deployment、Service、ConfigMap 等）。
   - 通过模板化（Templating）支持动态配置，允许用户通过变量（`values.yaml`）定制部署参数。
2. **Repository（Repo）**  
   - Chart 的存储仓库，类似于 Docker Hub 或 Maven Central，例如 [Artifact Hub](https://artifacthub.io/)。
   - 用户可以发布自己的 Chart 或使用社区维护的公共 Chart（如 MySQL、Redis 等）。
3. **Release**  
   - 在 Kubernetes 集群中运行的 Chart 实例。例如，同一 Chart 可以部署多次，生成多个独立的 Release（如 `dev-mysql` 和 `prod-mysql`）。
---

### **为什么需要 Helm？**

- **简化部署**：避免手动编写大量 YAML 文件，通过 Chart 实现“一键部署”。
- **配置管理**：通过 `values.yaml` 统一管理环境差异（开发、测试、生产）。
- **版本控制**：支持 Chart 版本化和回滚，确保应用升级的安全性。
- **依赖管理**：Chart 可以声明依赖其他 Chart（如 Web 应用依赖数据库），自动解决依赖关系。
---

### **Helm 的工作原理**

1. 用户通过 `helm install` 命令安装 Chart，生成一个 Release。
2. Helm 结合模板和 `values.yaml` 渲染出最终的 Kubernetes 资源文件。
3. 资源文件被提交到 Kubernetes API Server，由集群创建实际资源（Pod、Service 等）。
---

### **示例使用场景**

```Bash
# 安装
curl https://raw.githubusercontent.com/helm/helm/main/scripts/get-helm-3 | bash

# 添加官方仓库
helm repo add bitnami https://charts.bitnami.com/bitnami

# 更新
helm repo update

# 查看所有版本
helm search repo bitnami
helm search repo bitnami/mysql --versions | head -20

# 拉取模板（看CHART VERSION）
helm pull harbor/harbor --version 1.14.0 --untar

# 测试安装
helm install my-mysql bitnami/mysql --values=my-custom-values.yaml --dry-run --debug

# 安装 MySQL Chart
helm install my-mysql bitnami/mysql --values=my-custom-values.yaml

# 安装 MySQL Chart（本地）
helm upgrade --install my-mysql . --values=my-custom-values.yaml

# 升级 Release ( 或者安装, 推荐）
helm upgrade --install my-mysql bitnami/mysql --version 9.0.0

# 查看历史版本
helm history my-hami-webui -n kube-system

# 回滚到旧版本
helm rollback my-mysql 1

## 传统方式（已添加 repo）
helm show values cilium/cilium --version 1.17.11 > cilium-values.yaml

## OCI 方式（无需 repo）
helm show values oci://quay.io/cilium/charts/cilium --version 1.17.11 > cilium-values.yaml

# 使用template 模板渲染
helm template my-grafana grafana/grafana

# 使用自定义 value.yaml 文件渲染
helm template my-grafana grafana/grafana -f values.yaml -n <namespace> > render.yaml

# 查看所需镜像
grep -oP 'image:\s*\K[^"]+' render.yaml | sort -u

# 卸载
helm uninstall my-hami-webui -n kube-system

# 查看所有安装的列表
helm list -A
```

### 生产环境推荐

```Bash
# 生产环境推荐命令（含保护和等待）
helm upgrade --install cilium helm \
  --namespace kube-system \
  --create-namespace \
  --values helm/values.yaml \
  --atomic \          # 失败自动回滚
  --wait \            # 等待所有 Pod Ready
  --timeout 10m \     # 超时时间
  --cleanup-on-fail   # 失败时清理新创建的资源
```

如果是oci前缀的，则不能使用repo来管理

## 使用Harbor来管理helm

```Bash
# 下载示例
helm pull gitlab/gitlab-runner --version 0.90.1

# 登录
helm registry login harbor.cnzbai.com -u admin -p Harbor12345

# 推送到helm项目下
helm push gitlab-runner-0.90.1.tgz oci://harbor.cnzbai.com/helm

# 查看 Harbor 中的 chart
helm show chart oci://harbor.cnzbai.com/helm/gitlab-runner --version 0.90.1

# 单独下载 values.yaml 文件
helm show values oci://harbor.cnzbai.com/helm/gitlab-runner --version 0.90.1 > values.yaml

# 查看 渲染的配置
helm template oci://harbor.cnzbai.com/helm/gitlab-runner --version 0.90.1 -f values.yaml -n gitlab-runner > render.yaml

# 部署
helm upgrade --install cilium oci://harbor.cnzbai.com/helm/gitlab-runner \
  --version 0.90.1 \
  --namespace gitlab-runner \
  --create-namespace \
  --values values.yaml
```
