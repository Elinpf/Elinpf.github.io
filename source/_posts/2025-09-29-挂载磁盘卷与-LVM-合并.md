## LVM 扩展

```Bash
root@ceph-1:~# lsblk
NAME                      MAJ:MIN RM  SIZE RO TYPE MOUNTPOINTS
sda                         8:0    0   20G  0 disk 
├─sda1                      8:1    0    1M  0 part 
├─sda2                      8:2    0  1.8G  0 part /boot
└─sda3                      8:3    0 18.2G  0 part 
  └─ubuntu--vg-ubuntu--lv 252:0    0 18.2G  0 lvm  /
sdb                         8:16   0   20G  0 disk 
sr0                        11:0    1  3.1G  0 rom  

# 检查现有卷分组
sudo pvs
sudo vgs
sudo lvs

# 扩展
pvcreate /dev/sdb
vgextend ubuntu-vg /dev/sdb
lvextend -l +100%FREE /dev/ubuntu-vg/ubuntu-lv
resize2fs /dev/ubuntu-vg/ubuntu-lv
```

**如果遇到**50G只用了30G

```Bash
root@linux-host:~/shared# lsblk
NAME                      MAJ:MIN RM  SIZE RO TYPE MOUNTPOINTS
sda                         8:0    0   50G  0 disk 
├─sda1                      8:1    0    1M  0 part 
├─sda2                      8:2    0    2G  0 part /boot
├─sda3                      8:3    0   30G  0 part 
│ └─ubuntu--vg-ubuntu--lv 252:0    0  530G  0 lvm  /
└─sda4                      8:4    0   18G  0 part 
sdb                         8:16   0  500G  0 disk 
└─ubuntu--vg-ubuntu--lv   252:0    0  530G  0 lvm  /
sr0                        11:0    1    4M  0 rom  
```

这样的情况，50G中，sda3只用到了30G，那么就需要创建一个sda4，然后lvm分卷了

创建分区的方法

```Markdown
fdisk /dev/sda
在 fdisk 交互中依次输入：
n（新建分区）
p（主分区） # 没有这个
4（分区号）
直接回车（默认起始扇区）
直接回车（默认结束扇区，使用全部剩余空间）
t（修改类型）
4（选择分区 4）
8e（设置为 LVM 类型）
w（保存并退出）
```

```Bash
pvcreate /dev/sda4
vgextend ubuntu-vg /dev/sda4
lvextend -l +100%FREE /dev/ubuntu-vg/ubuntu-lv
resize2fs /dev/ubuntu-vg/ubuntu-lv
```
