    清理cuda 13.0

    #!/bin/bash
echo "开始彻底清理CUDA 13.0..."

    
# APT卸载
sudo apt-get --purge remove cuda-toolkit-13-0 "*cuda*" "*cublas*" "*cudnn*" "*cufft*" "*curand*" "*cusolver*" "*cufft*" -y
sudo apt-get autoremove -y
sudo apt-get autoclean

    
# 手动删除文件
sudo rm -rf /usr/local/cuda-13.0 /usr/local/cuda
sudo rm -f /etc/ld.so.conf.d/cuda-13-0.conf
sudo rm -f /etc/apt/sources.list.d/cuda-13-0-local.list
sudo rm -f /etc/profile.d/cuda.sh
sudo rm -f /usr/share/keyrings/cuda-archive-keyring.gpg

    
# 清理环境变量（在.bashrc中）
sed -i '/cuda-13.0/d' ~/.bashrc
source ~/.bashrc

    
echo "清理完成！请重启系统以彻底清除内核缓存。"
echo "重启命令：sudo reboot"

    # 1. 验证APT包是否清空

# 应该**没有结果**

    
# 3. 验证环境变量

# 5. **重启系统**（必须！清除内核模块缓存）
sudo reboot

    NVRM: The NVIDIA GPU ... requires use of the NVIDIA open kernel modules.
NVRM: loading NVIDIA UNIX x86_64 Kernel Module  590.44.01

    你的系统处于矛盾状态：安装了nvidia-driver-open包（开源驱动元包），但内核模块签名验证失败，且缺少关键的Fabric Manager服务。

    问题根源

    B200 GPU要求：

    1. 必须使用开源内核模块（日志明确提示）
    2. 必须安装并启动nvidia-fabricmanager服务（多GPU通信必需）
    3. 模块签名问题导致驱动无法完全初始化

    清理脚本

    #!/bin/bash
set -e

    
echo "========================================"
echo "  NVIDIA/CUDA 完全通用清理工具"
echo "========================================"
echo "⚠️ 警告：这将自动检测并移除系统上所有 NVIDIA/CUDA 版本"
echo ""

    
read -p "是否继续? (y/N): " -n 1 -r
echo
if [[ ! $REPLY =~ ^[Yy]$ ]]; then
    echo "操作已取消"
    exit 1
fi

    
# 1. 停止所有 NVIDIA 相关服务
echo "停止 NVIDIA 服务..."
sudo systemctl stop nvidia-persistenced.service 2>/dev/null || true

    总结

    1. 由于这次的B200 是SXM的制式, 采用第四代NVSwitch,
      1. 加入了NVLSM
      2. 所以需要安装 FabricManager
    2. FabricManager 依赖 nvlsm, 所以也需要同步安装
    3. 需要保证 nvidia 驱动版本, cuda 版本完全一致才行, 否则直接重装
    4. nvidia-smi 是安装cuda驱动才可以使用的
    5. 要使用开源的nvidia驱动(nvidia-open), 否则会直接找不到device(在dmesg中会明确写出来)
    6. 清理cuda 和nvidia驱动, 使用的是4层清理法
    7. 当出现问题, 从nvidia 驱动版本, cuda 驱动版本, nvidia-fabricmanager 运行状态, dmesg 日志等地方来排查
